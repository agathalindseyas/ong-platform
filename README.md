# ong-platform
Projeto curso de ADS - disciplina de Desenvolvimento front-end para web
_Atualização: teste de acessibilidade final._
# 🌱 Instituto Exemplo — Plataforma de Projetos Sociais

Projeto desenvolvido em 4 entregas para construção de uma aplicação web responsiva, acessível e versionada com Git/GitHub.

## 📦 Entrega 4 (Final)
- Controle de versão com GitFlow (`main`, `develop`, `feature/*`)
- Commits semânticos
- Pull Request documentado
- Release com versionamento semântico (`v1.4.0`)
- Acessibilidade (WCAG 2.1 AA): skip link, navegação por teclado, aria, foco visível
- Modo escuro e alto contraste
- CSS, JS e HTML minificados
- Imagens otimizadas
- Deploy no GitHub Pages

## 🚀 Tecnologias
- HTML5 semântico
- CSS modular (tokens, base, layout, nav, components, utilities)
- JavaScript ES6 (SPA por hash)
- Git e GitHub

## ♿ Acessibilidade
- `aria-label`, `aria-expanded`, `role="menu"`
- Skip link (`Ir para o conteúdo principal`)
- Navegação por teclado no menu e dropdown
- Contraste adequado
- Tema escuro e alto contraste (`data-theme="dark" | "high-contrast"`)
